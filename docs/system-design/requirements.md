# Requirements

## Functional requirements

- Users can create accounts and sign in.
- Users can browse songs, albums, and artists.
- Users can search for tracks and playlists.
- Users can create and manage playlists.
- Users can listen to songs and view playback history.
- Recommendations should be generated based on listening patterns.

## Non-functional requirements

- API response time should be acceptable for browse/search flows.
- Authentication must be secure and stateless.
- Data should be persisted in PostgreSQL.
- System should be modular and scalable.
