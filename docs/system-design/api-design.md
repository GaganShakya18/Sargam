# API Design

## REST endpoints

- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/songs`
- `GET /api/songs/{id}`
- `GET /api/search?q=...`
- `GET /api/playlists`
- `POST /api/playlists`

## Response format

Responses should return JSON with consistent status codes and structured payloads for success and error cases.
